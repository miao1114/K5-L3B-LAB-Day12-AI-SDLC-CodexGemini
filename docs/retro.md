# Retro nhóm

## Rà soát Phase 4 — ghi nhận kỹ thuật, chờ phản hồi nhóm

- Retro Phase 2 bên dưới chưa có hành động cụ thể; chưa thể xác nhận đã thực hiện.
- Cải thiện: tách luật web/headless; dùng test biên, replay, proof và lệnh benchmark/soak.
- Chưa tốt: tài liệu cũ lẫn mới; thiếu reflections và runtime Linux kiểm clone sạch.
- Backend/UI: server chạy không đồng nghĩa UI/Shop đã tích hợp; cần kiểm browser thật.
- Lỗi AI đã phát hiện: giả định order/items sai trước PRD; ID HTML trùng giữa màn
  ẩn/hiện (Playwright); test cũ khóa version 1.2 khi manifest nâng 1.3 (regression).
- Đề xuất lần sau: chốt schema/owner sớm, CI clone sạch đa OS, hash source cùng proof,
  hoàn thành license/reflections trước release. Chưa ghi đề xuất thành việc đã làm.
- Cảm nhận thành viên, token/chi phí và thống kê review: cần nhóm xác nhận bổ sung.
